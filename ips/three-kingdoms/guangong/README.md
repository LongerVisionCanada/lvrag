# 关公 | Guan Gong

![关公（Guan Gong）](docs/assets/guangong-hero.png)

三国时期名将关羽，后世尊为“关公”，是忠义文化的重要象征。

## 简介 / Overview

关公主题围绕历史记载、文学故事与传统文化展开。项目明确区分史实、文学演绎和原创内容，努力提供有依据、易理解的文化讲述。

## 知识范围 / Knowledge Scope

- **历史 / History：** 史实记载（如《三国志》）
- **文学 / Literature：** 文学演绎（如《三国演义》）
- **文化 / Culture：** 民俗、信仰、艺术等
- **原创 / Original：** 本项目原创内容

> 本主题严格区分史实、文学演绎与原创内容。
